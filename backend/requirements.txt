# Creator OS backend runtime dependencies.
#
# Deliberately small: Creator OS ships as a local-first desktop application and
# must install without a compiler toolchain. Where a well-known library would
# have added a C extension for a modest amount of code, the functionality is
# implemented against the standard library instead:
#   - JWT (HS256)      -> app/services/security/tokens.py   (vs PyJWT)
#   - password hashing -> app/services/security/passwords.py (vs bcrypt/argon2)
#   - Prometheus       -> app/infrastructure/observability/  (vs prometheus_client)
