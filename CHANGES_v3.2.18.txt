AutoPilot 3.2.18 — Any image format accepted, regardless of script extension
==============================================================================

Real fix for your exact situation: you have all 25 Moses images ready,
just as .png instead of the .jpg the script names. Previously this
failed as "image not found" even though the image genuinely existed —
just under a different extension. Fixed.

WHAT CHANGED
--------------
Image lookup now tries the exact filename first (no change for the
normal case where extensions already match), and if that's not found,
falls back to the same base filename with any supported format:
jpg, jpeg, png, webp, bmp, tiff, tif — case-insensitive on the
extension too. Your script can say "nile_night_basket.jpg" and it will
correctly find "nile_night_basket.png" (or .webp, or .PNG, etc.) sitting
right next to it.

Fixed in BOTH places that look up scene images (the main lookup and a
self-heal fallback used when a project folder has moved) — found and
fixed both while making this change, for full consistency.
